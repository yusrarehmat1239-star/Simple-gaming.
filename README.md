Simple Gaming 🎮

Welcome to my C++ game project! This repository has three fun console games made with C++.

Games Included:
1. Tic Tac Toe: A classic game for two players!
2. Snake: Control the snake, eat the food, and grow longer without crashing!
3. Hangman: Guess the hidden word letter by letter before the game ends!

How to Run:
1. Download or clone this repository.
2. Open all the `.cpp` files in your C++ compiler (like Dev-C++ or Visual Studio).
3. Compile and run the program to see the game menu!
